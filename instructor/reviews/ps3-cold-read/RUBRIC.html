PS3 RUBRIC

PS3 grading rubric

PS3 is worth a maximum of 4 points. There are 48 scored tests, 24 in each of testme_part_1.jl and testme_part_2.jl. A test that cannot run counts as failed.

Score Requirements
0 No tests pass, including submissions where neither suite can run.
1 1–23 tests pass.
2 24–47 tests pass.
3 All 48 tests pass, but one or more requirements below are not met.
4 All 48 tests pass and all requirements below are met.

After all tests pass, the instructor checks that:

  • The three functions implement the specified LP construction and repeated solves, use model indices, preserve inputs, and handle invalid arguments and solver status. Values are computed from the supplied model rather than hard-coded for test cases.
  • The implementation and any helpers have accurate docstrings and comments that explain nonobvious choices. The supplied docstrings may be retained.
  • All required implementation is complete, with no unfinished TODOs or placeholder errors.
  • The production plot and data tables are generated by the submitted implementation and included in outputs/. Units and plotted quantities match the assignment.
  • All three written answers address the prompts with correct reasoning and the requested numerical evidence. The instructor grades the writing; the checker only detects missing answers and placeholders.

The instructor tests the submitted src/Compute.jl, any student helper files, and Include.jl in a clean assignment copy. The original model data, supplied utilities, driver, and tests are used for grading. Alternative optimal flux vectors are accepted when they satisfy the constraints and give the correct production rate. Passing all tests leaves the final score pending instructor review.

The initial-submission, revision, independent-work, and reference-solution policies in README.md apply.
