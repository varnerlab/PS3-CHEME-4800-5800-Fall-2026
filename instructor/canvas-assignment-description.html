Problem Set 3: Feeding a cell-free protein factory

Release: Saturday, October 3, 2026
Initial submission deadline: Saturday, October 17, 2026, at 11:59 PM ET
Maximum score: 4 points, plus one Magic Point on the optional Advanced track

How much protein can a cell-free reaction mixture make from a fixed amino-acid budget? Use linear programming to find the maximum production rate of deGFP, a green fluorescent protein, in an E. coli cell-free system. Compare two ways to use the budget: give each of the 20 amino acids an equal share, or let the solver divide it to maximize production.

On the release page, scroll to Assets and select Source code (zip). Extract the archive completely before beginning. This problem set is supported with Julia 1.12.7 and uses the JuMP, GLPK, and Plots packages, which the first command below installs.

Choose your track

TRACK.txt holds your track, standard or advanced. Leave it as standard until you start the optional Part 3.

  • Standard: complete three functions in src/Compute.jl (Parts 1–2) and questions 1–2 in responses.md, for up to 4 points.
  • Advanced: also complete supply_ranges (Part 3) and question 3, for one Magic Point.

On either track, Parts 1–2 and questions 1–2 set your score out of 4, so choosing Advanced never lowers it. The Magic Point requires a score of 4, all Part 3 tests passing, a satisfactory answer to question 3, and teaching-team review.

The starter code is intentionally incomplete, so the tests will fail initially. Do not modify the supplied tests, data, or submission checker to make an incomplete solution appear to pass.

Check your work

In VS Code, open the extracted assignment folder containing Project.toml, README.md, and check_submission.jl. Open a terminal in that folder and run: 

julia --startup-file=no --project=. -e 'using Pkg; Pkg.instantiate()'
julia --startup-file=no --project=. check_submission.jl

The first command installs the packages; run it once, and expect it to take several minutes. The second runs the submission checker, which reads TRACK.txt. On the Standard track, it runs testme_part_1.jl and testme_part_2.jl, with 24 tests per script and 48 tests total. The Advanced track adds the 24 tests in testme_part_3.jl.

The checker always writes MANIFEST.txt and warns if answers are missing or still contain TODO placeholders. After the tests pass, it saves the production plot and data tables in the outputs folder. Use them to answer the questions.

The checker does not upload anything to Canvas. Written responses are reviewed separately.

Submit to Canvas

  1. Zip the entire problem-set folder after running the checker, including your source code, TRACK.txt, responses.md, data, generated MANIFEST.txt, and outputs folder.
  2. Rename the archive to CHEME-4800-5800-PS3-<your netid>.zip.
  3. Replace the complete <your netid> placeholder, including the angle brackets, with your actual NetID. For example: CHEME-4800-5800-PS3-abc123.zip.
  4. Upload the ZIP file to this Canvas assignment before the initial deadline.

If you cannot fix every failing test, submit your current work for partial credit. You must submit something by the initial deadline to participate in the infinite-revision policy. If you make no initial submission, the assignment score is 0 and later revisions will not be accepted for credit.

Revisions

After the initial deadline, eligible students may revise and resubmit PS3 through the end of the semester, and may change tracks. Return to this same Canvas assignment, select New Attempt, and upload the revised ZIP file.

Canvas may label these revisions “late.” That is expected and does not create a penalty under the infinite-revision policy. Each revision will be graded, and the highest score earned will be retained.
